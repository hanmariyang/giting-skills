# 실측 (2026-10-28)

같은 재료로 「유튜브에 올릴 한국어 자막 out.srt 를 만들어줘」를 시켰다. Claude Code `-p`, 모델마다 3번.

- 재료: `words.json`(45초 분량 대본 열두 문장의 단어 시각) · `cuts.txt`(점프 컷 다섯) · 30fps.
  **진짜 녹음이 아니다.** `gen.mjs` 가 대본에 말 빠르기 초당 6~7음절, 문장 사이 쉼, 말 직전 컷을 붙여 만들었다.
- 스킬 없이: 위 문장 그대로.
- 스킬로: 끝에 「caption-sync 스킬로 해줘.」 한 줄. 이름을 안 넣으면 Haiku 가 스킬을 꺼내지 않았다(1번 시도).
- 채점: `node score.mjs` 가 `out/` 의 12개를 같은 기준(넷플릭스 한국어 · 컷 · 말 구간)으로 잰다.

| | 남은 문제 (3번) | 자막 수 | 글자 보존 |
|---|---|---|---|
| Haiku · 스킬 없이 | 21 · 19 · 25 | 5~6 | 79% · 100% · 100% |
| Haiku · 스킬로 | 1 · 1 · 0 | 12~13 | 100% |
| Sonnet · 스킬 없이 | 27 · 29 · 26 | 13~14 | 100% |
| Sonnet · 스킬로 | 0 · 0 · 0 | 13~14 | 100% |

- 스킬 없이 Haiku 는 문장 두세 개를 한 자막에 몰아 7초를 넘기고 한 줄에 30자를 넣었다. 한 번은 단어를 빼서 원문 글자의 79% 만 남았다.
- 스킬 없이 Sonnet 은 문장마다 자막을 잘 나눴지만 말 끝에서 바로 끊어(꼬리 10건) 컷과 2프레임 간격을 안 지켰다.
- 스킬로 Haiku 에 남은 1건은 「네」 한 마디의 최소 노출이다. Sonnet 은 그 자리를 옆 자막과 붙여 풀었다.
- ⚠️ 채점 도구가 스킬이 쓰는 도구와 같다. 그래서 「스킬로 0건」은 도구가 제 기준을 지켰다는 뜻이고, 이 실측이 보여 주는 것은 **스킬 없이 만든 자막이 공개 기준을 몇 번 어기는가**다.
- 처음 돌릴 때 이 실측이 도구 버그 셋을 잡았다(프레임 위에 없는 컷 시각, 그 때문에 1프레임 어긋난 컷 앞 끊기, 꼬리 0.49초를 미달로 셈). 고친 뒤 스킬 6번은 다시 돌렸고, 12개는 전부 고친 도구로 쟀다.
- 스킬 없이 Haiku 한 번은 권한을 묻다 파일 없이 멈춰 다시 돌렸다.
